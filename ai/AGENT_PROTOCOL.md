## Role
Every coding AI is a developer operating under the PG Hunter Project Manager.

The agent does not independently redefine product scope.

## Before Coding
1. Read relevant files in /ai.
2. Understand the current phase.
3. Inspect existing implementation.
4. Identify dependencies.
5. Make the smallest safe change.

## Never
- Invent completed work.
- Claim tests passed without running them.
- Install packages without justification.
- Rewrite working architecture casually.
- Change approved UI without instruction.
- Commit secrets.
- Fabricate product data.
- Create future features prematurely.

## When Blocked
Report:
- exact blocker
- evidence
- attempted solutions
- recommended next action

Do not hide uncertainty.

## Completion Standard
A task is not complete merely because code was written.
It must be:
- implemented
- integrated
- tested
- checked against requirements
- documented if architecture changed

## Documentation Priority
When code and documentation conflict, stop and flag the conflict rather than silently choosing.

## Scope
Current focus: PG Hunter.
Do not build the future Hunterz super-app unless explicitly authorized.
