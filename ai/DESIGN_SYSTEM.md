## Visual Rules
- Minimal borders
- Soft, restrained shadows
- Strong typography
- High information density
- No unnecessary gradients
- No excessive glassmorphism
- No generic stock illustrations
- Avoid clutter
- Use icons consistently

## Property Cards
Must prioritize:
1. Video/image
2. Verification
3. Price
4. Distance
5. Room type
6. Rating
7. Key amenities

## Accessibility
- Minimum 44x44px touch targets
- Keyboard accessible controls
- Visible focus states
- Minimum WCAG AA contrast target
- Meaningful alt text
- Do not communicate status by color alone

## Responsive
Mobile-first. Desktop is an enhancement, not a separate product.
