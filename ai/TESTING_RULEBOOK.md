## Minimum Checks
Before completing a feature:
- production build
- TypeScript check
- relevant automated tests
- manual browser test
- mobile viewport test

## Homepage
Verify:
- navigation
- search controls
- responsive layout
- property cards
- video thumbnails
- verification badges
- buttons
- accessibility basics

## Search
Verify:
- valid query
- no results
- filters
- sorting
- loading
- errors

## Authentication
Verify:
- sign in
- sign out
- unauthorized access
- session expiration
- protected routes

## Management
Verify:
- owner permissions
- student permissions
- message privacy
- file access
- bill visibility
- maintenance visibility

## Security Testing
Test authorization, not just authentication.

## Regression
Do not declare a new feature complete if it breaks an existing approved flow.
