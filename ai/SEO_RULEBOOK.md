## Goal
Own useful search intent around student accommodation.

## Priority Landing Pages
Examples:
- PGs near DTU
- PGs near NSUT
- PGs near IIT Delhi
- PGs near IIIT Delhi
- PGs in Rohini
- PGs near [college]
- Boys PG near [college]
- Girls PG near [college]
- Rooms near [college]

## Property Pages
Every indexable property should have:
- unique title
- useful meta description
- canonical URL
- structured content
- location
- rent
- room type
- amenities
- verification status where true

## Content
Never create thousands of thin pages just for keywords.
Every landing page must provide genuine student value.

## Technical
- semantic HTML
- clean URLs
- sitemap
- robots rules
- canonical URLs
- Open Graph metadata
- structured data where appropriate

## Truth
SEO must never be achieved by fabricating listings, prices, reviews or availability.
